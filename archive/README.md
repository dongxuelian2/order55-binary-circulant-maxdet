# Archived order-15 μ₃ research run

This directory is a frozen, human-readable index of the order-15 handoff.  The
source of executable truth remains `order15_mu3/` plus `src/maxdet/` and the
pytest suite.  Stage notes summarize only claims that have a corresponding
script or recorded historical source; timeouts and partial searches are marked
as such.

- `stages/INDEX.md` — chronological stage index.
- `manifests/order15_mu3_manifest.json` — paths and replay metadata.
- `../results/handoff_checkpoint.json` — exact machine checkpoint.
- `../docs/HANDOFF.md` — collaborator-facing overview.

Transient virtual environments, caches, credentials, and uncommitted solver
logs are intentionally not archived.
